# HELIOS

This Project deals with Building a World model that can somewhat accurately and efficient predict the Future state of a Given Simulation, while  provided the Past of that given Simulation. It is basically a RNN or recurrent neural network that is trained to predict states of physics than a given text or data.

This Project specifically deals the N Body Problem.

The N Body problem is a Challenge that focuses on predicting the individual movement  of 3 or more celestial objects that interact with each other through Gravity. This project focuses on the classical N body problem that uses Newtons Gravitational formula, instead of Einstein's General Relativity  definition for Gravity. This Makes it much Simpler and computationally cheaper to start out with.

The Main Objective of this Project is not  to solve the N Body problem, but to attempt to unify the best of the Major 4 Types of World Models in order to produce the Model with the highest performance when predicting the N Body Problem. It thinks to Combine, Slot based World Models, Graph Neural Networks(GNN's), Recurrent Space State Models(RSSM's) and Joint Embedding Predictive Architecture. and Specifically it uses Hamiltonian Graph Neural Network(hGNN), Hence why  it is called HELIOS or Hamiltonian Embedding Latent Inference Orbital System. An Equivariant Graph Neural Network(EGNN) may also be used in place of the Slot Based Encoder.
